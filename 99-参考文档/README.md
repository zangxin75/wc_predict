# 99-参考文档

历史归档 / 已废止方案 / 阶段性备份。

## 用途

按 `~/.claude/CLAUDE.md`「Document Management Standards」约定,本目录用于:

- ✅ **旧版本文档**:被新版本取代的方案、报告(保留备查)
- ✅ **阶段性备份**:完成某个里程碑时的快照(避免丢失早期思路)
- ✅ **已废止实验**:被证伪/不再适用的代码片段、笔记
- ✅ **参考材料**:从外部引入但不再维护的引用

## 不放什么

- ❌ 当前活跃文档 → 留在 `01-项目规划/`、`04-技术方案/` 等原分类目录
- ❌ 临时调试输出 → 用完即删
- ❌ 配置文件副本 → 留在原位,通过 git 管理

## 入档流程

1. 在文件名前加版本后缀(如 `安全审计_v0.9_20260615.md`)
2. 移动文件到本目录
3. 在本表登记一行

## 季度清理

每季度最后一周检查:

- [ ] 超过 6 个月未访问的归档 → 考虑删除
- [ ] 引用了具体 PR / commit 编号的归档 → 校验引用是否仍可追溯
- [ ] 归档大小超过 5MB → 压缩为 `.tar.gz`
