# 需求表:tournament_sim(2026 世界杯整届蒙特卡洛推演)

## 模块职责
用 Elo 模型对整届世界杯做 N 次蒙特卡洛模拟,统计各队夺冠概率。
覆盖 2026 新赛制:12 组×4 队单循环 → 32 强(24 + 8 最佳第3) → 5 轮淘汰赛。

## 数据流
```
wc2026_schedule.csv(分组) + build_elo(Elo) → 单循环抽比分 → 积分排名 →
  32 强 seed → 标准签表淘汰赛(平局 resolve_knockout_draw)→ 冠军
                                                              × N 次
                                                          夺冠频率表
```

## 赛制细节(2026)
- **小组赛**:每组 4 队单循环 6 场;积分(胜3平1负0)→ 净胜球 → 进球 排名
- **出线**:每组前 2 名(24 队)+ 跨组 8 个最佳第 3 名(8 队)= 32 强
- **淘汰赛**:32 强按 Elo 降序 seed,标准签表(最强两 seed 分处上下半区)
- **平局**:小组赛允许平;淘汰赛 90 分钟平 → ★resolve_knockout_draw(learning 点3)

## learning 点 3:resolve_knockout_draw(team_a, team_b, lam_a, lam_b, rng)
默认实现:加时 30 分钟泊松(λ×0.33)+ 点球 50:50。扩展方向见函数注释。

## 验收(计划 Verification #5)
`python tournament_sim.py --sims 10000` → 夺冠概率 Top10 符合直觉(阿根廷/法国/西班牙居前)。
实测(2000 次,seed=42):西班牙 22.75% / 阿根廷 17% / 法国 11.55% 居前三 ✓

## 已知简化(后续改进点)
- 东道主(美国/墨西哥/加拿大)主场加成未建模(全中立场 home_adv=0)
- seed 用纯 Elo(真实赛制组冠军不打组冠军,简化为 Elo 排序)
- 西班牙绝对值偏高(~23%):Elo+泊松方差在淘汰赛放大最强队优势,需 XGBoost/集成校准
