# B 方案价值下注结论(2026-06-19)

## 一句话结论
**Elo 模型已被历史数据最优校准,与市场高度一致(corr +0.87),B 方案理论不可行。**

## 背景
继 A 方案(跨博彩套利)上线后,验证 B 方案(系统预测 vs 市场赔率 = 价值下注)。
期望:如果 Elo 对某结果概率 > 市场 devig 后概率 + 阈值(edge),即"价值信号"。

## 校准结果(`calibrate_elo.py`)
数据:295 场世界杯历史比赛(1998-2022)+ BetExplorer 收盘赔率

|---|---|---|
| Brier Score | 0.0237 | 已被网格搜索最优 |
| Elo vs 市场 corr(主胜) | +0.868 | 高度一致 |
| Elo vs 市场 corr(客胜) | +0.869 | 高度一致 |

参数扫描(Total × Scale × ρ × DrawBoost)全部无改善 → 当前配置已最优。

## 实测价值扫描(`scan_value_bets.py`)
- **已赛 28 场**:odds_wc.csv 没有赛前赔率(比赛 fetch 时已撤盘),无法回测
- **未赛 72 场**:扫描出 36 场 edge ≥ 3%,看似"信号满满",但:
  - 平均 edge 11.3%,中位 7.1%
  - 29 场 edge ≥ 5%,14 场 ≥ 10%
  - Top 1 Kelly 76.4%(厄瓜多尔 vs 库拉索)

## 关键洞察:大 edge 多在"冷门队"
厄瓜多尔 Elo=1980,库拉索 Elo=1600 → Elo 给主胜 77%,但市场赔率 27.0
(隐含 4%)。Elo vs 市场差距 73%。

类似大 edge 集中出现在:
- 库拉索 / 海地 / 佛得角 / 巴拿马(加勒比海 + 非洲小国)
- 这些队伍 Elo 数据稀疏(5-15 场国际赛),模型不确定性高

**真实市场比 Elo 准的原因**:
- 博彩公司团队对每个队都有内部 rating(近期战绩、阵容、伤停)
- 我们只靠 295 场历史 + Dixon-Coles 模型,信息严重落后
- **职业价值下注团队盯 Pinnacle/Betfair 一旦发现 73% edge 立即吃掉** → 实际不存在 = 模型在错的方向过度自信

## A vs B 方案对比

| 维度 | A 套利(跨博彩) | B 价值下注(Elo vs 市场) |
|---|---|---|
| 数学正确性 | ✓ 严格套利 sum<1 | △ 依赖模型校准 |
| 实战可执行性 | ⚠ 需多家账号 + 软盘撤单风险 | ✗ 模型对冷门队不可信 |
| 预期 ROI | 小(~0.5%) | **负**(佣金 + 模型偏差吃光) |
| 推荐 | 仅作监控/研究 | **不建议执行** |

## 实用建议
1. **不要按 Kelly 比例下注** — 模型未在冷门队上验证过
2. **价值在监控**:继续跑 `scan_value_bets.py`,关注是否出现"主流对阵持续 ≥ 5% edge"(那才是真信号,几乎不会出现)
3. **真信号触发条件**:小组赛 30+ 场打完且 fetch 抓到收盘赔率,做真实已赛回测
4. **作为教学工具**:webapp 新增"价值下注" tab(`/api/value-bets`),可视化 Elo vs 市场对比,纯展示
